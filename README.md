# DKU Dev Portal

질문에 답하면 서버가 만들어지는 셀프서비스 서버 포털 프로토타입입니다.
서버 생성부터 관리, 배포까지의 흐름을 화면으로 보여 줍니다.
서버 없이 브라우저만으로 동작하고, 데이터는 브라우저(localStorage)에 저장됩니다.

## 실행

`login.html`을 브라우저로 열면 됩니다. VS Code를 쓴다면 Live Server로 열어도 됩니다.

로그인은 데모 계정이 미리 입력되어 있어서 버튼만 누르면 됩니다.

- 아이디: `soft2021`
- 비밀번호: `dku2026`

## 사용 방법

처음이라면 Home에서 "질문으로 추천받기"를 눌러 따라가 보세요.

사용자 가이드는 [DKU_Dev_Portal_소개.pdf](DKU_Dev_Portal_소개.pdf)에 있습니다. 화면을 따라가면서 주요 기능을 설명한 자료입니다.

저장된 데이터를 처음 상태로 되돌리려면 My Page 아래쪽의 "데모 데이터 초기화"를 누르세요.

## 구성

- `assets/catalog.js`: 사양, 요금, 정책 같은 상수
- `assets/state.js`: 상태와 계산 로직
- `assets/app.js`: 화면 동작
- `assets/styles.css`: 스타일
